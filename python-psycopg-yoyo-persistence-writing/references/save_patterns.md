# Сохранение одной записи и пачки

## Одиночное сохранение

Не оборачивать один объект в коллекцию. Публичный `save` выбирает операцию по
контракту и делегирует в `_create` либо `_update`; приватные методы используют
`execute`.

Не считать `version == 1` универсальным признаком создания. Если такая семантика
задана портом, реализовать её буквально.

## Пакетное сохранение

- Материализовать iterable один раз.
- Завершать пустой вызов без SQL.
- Разделять записи одним проходом.
- Преобразовать все параметры до первого SQL-вызова.
- Вызывать `_batch_create` и `_batch_update` не более одного раза на группу.
- Использовать `executemany`.
- Не удалять дубликаты и не менять порядок молча.
- Сохранять одинаковую семантику одиночной и пакетной операций.

Чистые `_to_create_params`/`_to_update_params` переиспользовать между вариантами
и покрывать unit-тестами без cursor-моков.

## Версия и конфликты

- Включать ожидаемую сохранённую версию в `WHERE` optimistic update.
- Проверять `rowcount`; нулевой результат — конфликт, если так задано портом.
- Для пачки сверять число изменённых строк с числом параметров.
- Частичный конфликт преобразовывать в `AppPortError`; UoW откатывает транзакцию.
- Не выполнять автоматическое перечитывание, повтор или last-write-wins.
- Использовать version/outbox DTO как самодостаточный неизменяемый снимок.

## Частичное обновление

- Различать `UNSET`, `None` и переданное значение.
- Сопоставлять разрешённые поля с заранее заданными `Identifier`.
- Строить `SET` только из переданных полей.
- Не выполнять SQL для пустого изменения, если контракт не требует иного.
- Не заменять partial update полной перезаписью после чтения.
- Включать scope и ожидаемую версию в тот же `UPDATE`.

## Удаление

- Выполнять физический `DELETE` только по контракту.
- Сохранять domain soft delete как изменение агрегата.
- Не предполагать каскад без подтверждённой миграции.
- Проверять `rowcount`, если отсутствие и успех различимы.
- Не превращать отсутствие в успех без заданной идемпотентности.
- Не использовать `TRUNCATE` как repository-операцию.

## Идентификаторы и время

Получать доменный ID, значимое время, editor и версию уже назначенными. Не
генерировать их репозиторием и не заменять `NOW()`. DB-generated технические
значения допустимы только внутри адаптера.
