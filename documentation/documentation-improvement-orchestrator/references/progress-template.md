Использовать шаблон для `.orchestration/documentation-progress.md`. Файл не
является нормативной документацией и не должен добавляться в Git. Если строк
`.orchestration/` и `.review/` нет в корневом `.gitignore` целевого проекта,
предложить пользователю добавить их и не изменять файл без согласия.

Допустимы только следующие статусы элементов:

- `Не начато` — элемент входит в область, работа ещё не начата;
- `В работе` — элемент создаётся, изменяется или проверяется;
- `Выполнено` — элемент подготовлен и относящиеся проверки успешны;
- `Заблокировано` — требуется решение пользователя или недоступный источник;
- `Не требуется` — элемент рассмотрен и доказанно не входит в область.

## Правила ведения

- Назначать стабильные ID `DOC-001`, `DEC-001`, `BLOCK-001` и далее.
- Не ставить `Выполнено` до локальной проверки и повторного аудита, когда он нужен.
- Не записывать предположение в `Принятые решения`.
- Сохранять формулировку и смысл ответа пользователя.
- После решения обновлять связанный блокер, замечание и нормативный документ.
- Не удалять прежние решения и сведения предыдущего запуска.
- Держать `Следующий шаг` непустым до выполнения Definition of Done.
