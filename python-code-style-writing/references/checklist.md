# Чеклист Python code style

- Составные условия из трёх и более предикатов имеют смысловое имя либо разбиты
  на guard clauses.
- Простые условия не обёрнуты лишними boolean-переменными.
- Enum сравниваются напрямую; методы-предикаты отдельных значений отсутствуют.
- Метод выполняет одну связную операцию.
- Однострочные private wrappers имеют самостоятельную причину существования.
- Публичные члены класса расположены выше protected/private.
- Файлы длиннее 300 строк проверены на смешение ответственностей.
- Абстрактные методы содержат только `...`.
- Неиспользуемые и wildcard imports отсутствуют.
- Конкретные импорты предпочтены там, где пространство имён модуля не нужно.
- Аргументы проектных исключений с именованной сигнатурой переданы по именам;
  встроенная позиционная сигнатура сохранена, совпадающие defaults не повторены.
- Изменение не содержит несвязанного массового форматирования.
- Линтер и форматировщик текущего проекта прошли.
