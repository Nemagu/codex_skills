# Проверка документации HTTP API

## Полнота структуры

- Области и версии разделены.
- Каждый ресурс, endpoint и модель имеет документ.
- `SUMMARY.md` содержит все актуальные документы и не содержит удалённых.
- Локальные ссылки и сборка документации проверены.
- Стабильные обозначения уникальны и включают область и версию.

## Полнота endpoint-а

- Метод и полный адрес однозначны.
- Каждый входной источник описан поле за полем.
- Коллекции, фильтры, сортировка и пагинация не оставляют решений реализации.
- Отсутствие, `null`, пустое значение и неизвестные поля различены.
- Вход полностью сопоставлен application-входу.
- Результат полностью сопоставлен внешнему ответу.
- Статус, заголовки, тело и отсутствие тела зафиксированы.
- Общие ошибки не продублированы; отклонения указаны локально.
- Повтор и совместимость определены.
- Есть согласованные примеры.
- Открытые вопросы соответствуют реальным пробелам.

## Границы

- HTTP-модели не названы application DTO.
- Domain-ошибки не преобразуются presentation напрямую.
- Бизнес-валидация не выдана за транспортную.
- Не закреплены фреймворк, библиотека, класс или способ реализации.
- Код не использован без разрешения.
